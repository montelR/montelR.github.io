## Purpose

Project Sentinel connects practical Linux administration with modular AI infrastructure. The homelab includes service management, backups, monitoring and recovery documentation. The runtime explores model interfaces, specialist delegation, memory and tool authorization.

## Selected evidence

A historical Sentinel API checkpoint recorded 88 passing backend tests. A separate opt-in diagnostic tool benchmark preserved original output while reducing the size of selected noisy summaries. These are recorded project measurements, not a fresh validation of live services.
