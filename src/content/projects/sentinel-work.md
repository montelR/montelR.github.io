## Purpose

Sentinel Work explores how a browser-assisted workflow can preserve clear control boundaries, distinguish observed outcomes from assumptions, and avoid repeating uncertain actions.

## Engineering approach

A workflow controller coordinates browser state, verified inputs, human review and evidence. Synthetic browser fixtures isolate failure modes before changes are considered for release.

## Selected evidence

- [When successful interaction is not proof of authorization](/case-studies/agent-session-reliability/): reproduce a failure, add a regression and review a corrected revision.
- [Why passing tests did not justify release](/case-studies/evaluation-release-gates/): a matched evaluation with a predeclared decision gate.

## Scope and contribution

This is independent project work. The case studies summarize historical, documented project outcomes. I direct the project goals, architecture and release decisions, and work with AI coding assistants on implementation, debugging, testing and documentation. Private source, operational details and real applicant data are intentionally excluded.
